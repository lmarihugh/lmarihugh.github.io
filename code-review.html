Code review

A walkthrough of all three of my enhancements: the existing code, the areas I planned to improve, and the skills I set out to demonstrate.

Watch the video on YouTube if it does not play above.

What the review covers

  • Existing functionality. How the Event Tracking App and the Thermostat worked before any enhancements.
  • Code analysis. The areas I targeted for improvement, such as structure, logic, efficiency, functionality, security, testing, and documentation.
  • Planned enhancements. What I planned to change in each artifact and which skills and course outcomes each change would demonstrate.

Changes since the review

A few details changed between the video and the finished work. This is where the final code differs from what I described:

  • Password hashing. I planned SHA-256 with a salt, and the final version uses PBKDF2 with a random salt per user, because the iteration count makes each guess harder.
  • Database index. The final version indexes events.username only. The users.username column is already indexed because it is the primary key.

Event Tracking App

A Java based Android app for tracking events, originally built for CS 360. I used this one app for two of the three capstone categories: software design and engineering, and databases.

The app has a login page, a dashboard, and an event editor. There is also an SMS reminder for an event if the user wants. I enhanced the same code base twice, first for software design (Milestone Two) and then for databases (Milestone Four), so the enhanced code and the tests include both sets of changes.

The two enhancements

Software design and engineering

Milestone Two

Before: The dashboard was hardcoded with event slots, which would not allow for scale.

After: An Event class, an EventRepository that owns all database access, a RecyclerView with an EventAdapter, and input validation in EventValidator. Backed by 16 automated tests.

View more information →

Databases

Milestone Four

Before: Passwords were stored as plain text, and events were not tied to users by a foreign key.

After: Salted PBKDF2 password hashing, a foreign key from events to users with cascade delete, an index on events.username, and a version 2 database migration.

View more information →

Key result: The dashboard is no longer built on fixed event slots, and passwords are no longer stored as plain text.

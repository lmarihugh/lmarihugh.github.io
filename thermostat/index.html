Raspberry Pi Smart Thermostat

A Python state machine for a Raspberry Pi that heats and cools based on a temperature sensor, built in CS 350 and enhanced to handle noisy sensor data.

The thermostat has three states (off, heat, cool) that a physical button cycles through. Red and blue LEDs show heating and cooling activity, an LCD shows the temperature and set point, and a background thread reports status over a serial connection. The enhancement focused on one weakness: the original compared a single raw sensor reading to the set point, so one noisy reading could flip the lights even when the room had not changed.

Before and after

Original

  • One raw reading compared directly to the set point
  • No averaging or smoothing
  • Sensor and serial failures could crash the display thread

Enhanced

  • TemperatureBuffer: a fixed-size rolling window of 7 readings
  • Lights decided from the smoothed average
  • try/except around the sensor read and serial write, with fallbacks
  • Window size chosen using a simulated noise comparison
Key result: in simulation, wrong light decisions near the set point fell from about 16% with a single reading to about 0.35% with a 7-reading window, for roughly one extra second of response lag compared to a window of 5. The simulation assumes 0.5°F of sensor noise; it is not a measurement from the physical sensor.
